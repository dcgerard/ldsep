# Package index

## All functions

- [`Dprime()`](https://dcgerard.github.io/ldsep/reference/Dprime.md) :
  Get the standardized composite D'.

- [`format_lddf()`](https://dcgerard.github.io/ldsep/reference/format_lddf.md)
  :

  Format an element of
  [`mldest()`](https://dcgerard.github.io/ldsep/reference/mldest.md) or
  [`sldest()`](https://dcgerard.github.io/ldsep/reference/sldest.md)
  into an upper-triangular matrix.

- [`get_prob_array()`](https://dcgerard.github.io/ldsep/reference/get_prob_array.md)
  : Obtain the distribution of genotypes given haplotype frequencies
  under HWE

- [`gl_to_gp()`](https://dcgerard.github.io/ldsep/reference/gl_to_gp.md)
  : Normalize genotype likelihoods to posterior probabilities.

- [`glike`](https://dcgerard.github.io/ldsep/reference/glike.md) :

  Genotype log-likelihoods from `uit`

- [`gp`](https://dcgerard.github.io/ldsep/reference/gp.md) :

  Posterior probabilities from `uit`

- [`hsm()`](https://dcgerard.github.io/ldsep/reference/hsm.md) :
  Half-sample mode estimator

- [`is.lddf()`](https://dcgerard.github.io/ldsep/reference/is.lddf.md) :

  Tests if an argument is a `lddf` object.

- [`ldest()`](https://dcgerard.github.io/ldsep/reference/ldest.md) :
  Pairwise LD estimation in polyploids.

- [`ldest_comp()`](https://dcgerard.github.io/ldsep/reference/ldest_comp.md)
  : Estimates of composite pairwise LD based either on genotype
  estimates or genotype likelihoods.

- [`ldest_hap()`](https://dcgerard.github.io/ldsep/reference/ldest_hap.md)
  : Estimate haplotypic pair-wise LD using either genotypes or genotype
  likelihoods.

- [`ldfast()`](https://dcgerard.github.io/ldsep/reference/ldfast.md) :
  Fast bias-correction for LD Estimation

- [`ldshrink()`](https://dcgerard.github.io/ldsep/reference/ldshrink.md)
  :

  Obtain shrinkage estimates of correlation from output of
  [`mldest()`](https://dcgerard.github.io/ldsep/reference/mldest.md) or
  [`sldest()`](https://dcgerard.github.io/ldsep/reference/sldest.md).

- [`mldest()`](https://dcgerard.github.io/ldsep/reference/mldest.md) :
  Estimate all pair-wise LD's in a collection of SNPs using genotypes or
  genotype likelihoods.

- [`pbnorm_dist()`](https://dcgerard.github.io/ldsep/reference/pbnorm_dist.md)
  : Returns distribution of proportional bivariate normal.

- [`plot(`*`<lddf>`*`)`](https://dcgerard.github.io/ldsep/reference/plot.lddf.md)
  :

  Plot the output of
  [`mldest()`](https://dcgerard.github.io/ldsep/reference/mldest.md) or
  [`sldest()`](https://dcgerard.github.io/ldsep/reference/sldest.md)
  using [`corrplot()`](https://rdrr.io/pkg/corrplot/man/corrplot.html)

- [`pvcalc()`](https://dcgerard.github.io/ldsep/reference/pvcalc.md) :
  Calculate prior variances from a matrix of prior genotype
  probabilities.

- [`slcor()`](https://dcgerard.github.io/ldsep/reference/slcor.md) :
  Sliding window correlation

- [`sldest()`](https://dcgerard.github.io/ldsep/reference/sldest.md) :
  Sliding window LD estimation

- [`uit`](https://dcgerard.github.io/ldsep/reference/uit.md) : Updog
  fits on the data from Uitdewilligen et. al. (2013)

- [`zshrink()`](https://dcgerard.github.io/ldsep/reference/zshrink.md) :
  Shrinks Fisher-z transformed correlation estimates and returns
  resulting correlation estimates.
