# Tests if an argument is a `lddf` object.

Tests if an argument is a `lddf` object.

## Usage

``` r
is.lddf(x)
```

## Arguments

- x:

  Anything.

## Value

A logical. `TRUE` if `x` is a `lddf` object, and `FALSE` otherwise.

## Author

David Gerard

## Examples

``` r
is.lddf("anything")
#> [1] FALSE
# FALSE
```
