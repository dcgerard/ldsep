# Updog fits on the data from Uitdewilligen et. al. (2013)

10 SNPs from the "PGSC0003DMB000000062" super scaffold were genotyped
using the
[`multidog()`](https://dcgerard.github.io/updog/reference/multidog.html)
function from the updog R package. These data are the resulting output.

## Usage

``` r
uit
```

## Format

An object of class
[`multidog()`](https://dcgerard.github.io/updog/reference/multidog.html).
See the documentation from the updog R package.
